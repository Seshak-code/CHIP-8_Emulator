Instructions

Load any standard CHIP-8 or SuperCHIP (SCHIP) ROM file to begin playing.

  • Use the keys shown on the mapping grid to play.
  • Press ESC to halt execution.
  • Drag a new ROM into the window at any time to switch games.
Developed in C++ with WebAssembly compilation via Emscripten.
